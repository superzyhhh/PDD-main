# 无广告免费版独立成线，先上线验证再补广告与会员

我们以个体工商户主体先上线一个无广告、无会员、无生成式 AI 风格的免费版，用真实用户反响验证需求，用户量起来后再演进为含广告与会员权益的版本。免费版从 `pindo-miniapp` 一次性 fork 到 `preXCX`，此后 **`preXCX` 是主线**（唯一对外运行的版本），`pindo-miniapp` 保留为含 AI 风格与会员能力的完整版参照，在广告版立项前不再主动演进。

免费版范围定义为「全部功能 − 生成式 AI 风格 − 会员／购买／支付 − 291 进阶色卡档」，并顺带定了三个口径：高清导出不限次数（无会员时限额没有解锁路径，只产生挫败）、成品尺寸三档全开（算力超标时用排队与并发上限兜底，而不是砍档位）、「我的图纸」走云端最小持久化（先单实例存储，重启即丢并在界面上明示）。风格族保留「原图 + Q 版／线条风／平涂卡通／像素风」，全部由服务端本地算法完成。

**Considered Options：** 在同一份代码里用开关裁剪功能——少一份代码，但灰度判断与会员权益分支会长期留在主线上，免费版的「干净」是假的；以完整版为主线、免费版做旧分支——改动方向与用户方向相反，要先维护一套还没有用户的广告与会员逻辑。

**Consequences：** 同一 bug 需要在两条代码线上各修一次，接受这个代价；免费版有云成本而零收入，唯一的成本阀门是并发上限与大档排队，不设导出次数限制；291 进阶档、高级风格、会员与支付相关词不进本上下文的 Glossary，广告版立项时另写 ADR。
