## 2. 类目、名称与文案

1. 服务类目：**工具 → 图片处理**（备选：工具 → 效率）。不需要特殊资质。
2. 名称与简介里**不要出现「AI」「智能生成」「一键出图」等生成式表述**——免费版已不含生成式模型，写了既不符实，也会引入额外审核关注。

## 3. 隐私与合规（必做，缺一不可）

1. 在小程序后台填写**用户隐私保护指引**，逐项对应代码里真实用到的隐私接口（见知识文档 §10.1）：
   - 「选择照片或视频信息」——`wx.chooseMedia` 选图，用于生成图纸；
   - 「保存到相册（相册写入权限）」——`wx.saveImageToPhotosAlbum`，用于保存高清图纸；
   - 「写入剪切板」——`wx.setClipboardData`，材料清单「复制清单」按钮用到；
   - 如使用昵称/头像，单独声明。
2. 隐私接口授权：基础库 ≥2.32.3 平台会在首次调用隐私接口时弹官方授权弹窗，本项目直接依赖默认弹窗即可，不必自定义 `onNeedPrivacyAuthorization`（知识文档 §10.2）。
3. 小程序内提供**用户协议**与**隐私政策**入口（放在「我的图纸」页底部即可），内容需与实际收集行为一致。
4. 上传图片的内容安全：确认 `server/src/moderation.ts` 在未配置 AppID 时的失败策略。**上线时必须「校验失败即拒绝」**，不能静默放行。
5. 材料包的「去购买」外链：`config.js` 的 `PURCHASE_URL` 现在是空字符串（降级为复制清单）。若填外链，必须在小程序后台配置为**业务域名**（业务域名与 request 合法域名是两套配置）。

## 4. 服务端部署

无论选哪种，`wx.request` 与 `wx.downloadFile` 的目标域名都必须 **HTTPS + ICP 备案**，并在小程序后台「开发管理 → 开发设置 → 服务器域名」分别加入 **request 合法域名**与 **downloadFile 合法域名**——本项目两者都用到：上传图片走 `wx.request`，图纸/PDF 文件下载走 `wx.downloadFile`（知识文档 §6.1）。域名每月可修改次数有限，先定好再填；开发期可在开发者工具勾「不校验合法域名」，提审前必须取消并按真实域名跑一遍。

二选一：

**A. 微信云托管（推荐先用）**
- 用 `preXCX/Dockerfile` 构建，构建上下文是 `preXCX/` 目录，端口 80。
- 云托管会给出 HTTPS 域名，直接填到 `config.js` 的 `BASE_URL`，并在小程序后台加入 request 合法域名。
- 需要配置环境变量：`WX_APP_ID`、`WX_APP_SECRET`、`ADMIN_TOKEN`（看板口令）。
- 可选：小程序调用**同主体**云托管服务可改用 `wx.cloud.callContainer`，免配合法域名、免 HTTPS 证书（需改 `utils/api.js`，当前用 `wx.request`，不强求）。

**B. 自有云服务器**
- Docker 跑同一镜像，前置 Nginx + HTTPS 证书。
- 域名需 ICP 备案，否则无法加入小程序合法域名。
- 注意：免费版零收入，选最低配；唯一成本阀门是并发上限与大档排队，**不要**退回导出次数限制。

## 5. 看板口令

`/api/metrics/summary` 由 `ADMIN_TOKEN` 保护。部署时设一个长随机串，查看方式：

```
curl -H "x-admin-token: <ADMIN_TOKEN>" https://<域名>/api/metrics/summary
```

首版只留 API，不做管理页。
