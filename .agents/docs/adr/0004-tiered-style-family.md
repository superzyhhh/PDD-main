# 风格族分为免费风格与高级风格两层

拼豆新手的核心诉求是「上传即出图」，而生成式模型的调用成本、延迟与合规负担不适合做所有用户的默认路径。我们决定把风格族拆成两层：Q 版、线条风、平涂卡通、像素风由服务端本地算法转换，对所有用户免费且始终可用；动漫风、写实风依赖生成式模型（微信云开发 AI 图片生成），内测期对白名单开放，正式期作为会员权益。

**Considered Options：** 全部交给生成式模型——效果上限最高，但每张图都有调用成本与延迟，降级与离线不可控；全部用本地算法——成本最低，但做不出可信的动漫风与写实风，等于放弃高级风格这条产品线。

**Consequences：** 风格目录必须携带「免费/高级」与「是否需要生成式模型」两个属性，风格选择器的可用性、AI 标识、失败处理与看板拆分都按属性驱动，而不是按写死的风格列表驱动；本地风格的主要风险从「供应商稳定性」变成「算法质量」，需要固定素材的视觉回归基线来约束。
