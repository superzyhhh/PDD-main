# MARD 色卡数据以社区来源起步，商用前须替换或确认授权

`lib/data/palettes/mard.json` 现有 291 条色号，自带 Lab 值，但 `license` 标记为 `community`、`source` 为 `colorSystemMapping`，并非官方授权数据。v1 以该数据加厂商公开色值起步，对关键色做实物抽样实测校正，产品内不宣称「官方色卡」，上线前完成来源确认或替换为自建实测数据。取舍：立即自建全量实测的周期与成本过高，先用可接受精度换取验证速度，同时把法务敞口写明。

**Consequences：** 「比别家更准」这一卖点的精度上限受数据来源约束；进阶档 291 沿用同一来源，风险同源。
