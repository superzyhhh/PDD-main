# Triage Labels

技能用五个规范的分诊角色说话。本文件把角色映射到本仓库 tracker 实际使用的标签字符串。

| 技能中的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整规格化，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某个角色时（例如「打上 AFK-ready 分诊标签」），使用本表右列对应的字符串。若以后更换命名，直接改右列。
