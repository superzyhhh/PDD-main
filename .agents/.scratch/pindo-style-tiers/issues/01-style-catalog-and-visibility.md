# 01 — 风格目录分层与入口可见性

**What to build:** 用户打开生成页时，看到的风格族按「免费风格」与「高级风格」分组；免费风格永远可用，高级风格只有被授权时出现；预览页只对高级风格显示 AI 标识。

**Blocked by:** None — can start immediately

**Status:** ready-for-human

- [x] 服务端下发的风格目录包含原图、四种免费风格与两种高级风格，每项携带层级与「是否需生成式模型」属性
- [x] 免费风格在任何配置下都可用；未配置生成式模型时只有高级风格不可用，原图与免费风格行为不变
- [x] 高级风格仅对白名单（内测期）或会员（正式期）可用，不可用时客户端不展示该项
- [x] 生成请求提交不可用的高级风格时返回可识别的拒绝原因，且不创建任务
- [x] 预览页仅对高级风格展示 AI 标识，原图与免费风格不展示
- [x] 客户端按免费风格与高级风格分组展示，默认选中原图

## Comments

- 风格目录由单一描述表驱动：每个风格都必须声明分组与「是否需生成式模型」，新增风格时漏配会直接编译失败；接口下发项自带同样属性，客户端不按列表位置推断。
- 免费风格由本地转换器承接，因此未配置生成式服务时依然可用；未配置时只下发免费分组。
- 高级风格的放行条件是「生成式服务已配置」且「白名单或会员身份」；未授权提交返回可识别的拒绝原因，不创建任务。未提供白名单回调时默认拒绝，避免配置疏漏导致高级风格对所有人开放。
- 预览页的 AI 标识改为由任务/快照上的属性驱动，不再用「非原图」推断，免费风格不会误标。
- 免费风格的图像算法本轮只是可用的占位实现，观感质量由后续风格工单替换；本工单只保证可用性与分层可见性。
- 客户端在风格被拒时回落到原图并重新拉取分组；拉取分组失败时保留已有分组，不因一次请求失败隐藏免费风格。
- 未覆盖：真机冒烟（归工单 12 的验收流程）；高级风格的真实云函数连通性（工单 06）。
