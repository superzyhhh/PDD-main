# 04 — 平涂卡通

**What to build:** 用户选择平涂卡通后，照片被转成大面积纯色块加硬边轮廓的卡通图纸，仍直接由既有色卡出图。

**Blocked by:** 02

**Status:** ready-for-human

- [x] 平涂卡通端到端可用，三候选与既有不变量（色卡档、尺寸档、拼板数）成立
- [x] 输出以大面积纯色块与硬边轮廓为主，色号数明显收敛但主体结构保留
- [x] 同一原图下与 Q 版结果可区分，不止是色彩差异
- [ ] 四类素材的视觉回归通过并记录算法版本
- [x] 颜色量化后所有色号仍严格落在所选色卡档

## Comments

**算法**：工作图上先做中值滤波去纹理，再按每通道 4 级量化合并相近色，得到大面积纯色块；随后只在「跨两级及以上色阶」的边界描 3px 硬边轮廓。与 Q 版的区别在勾边密度：Q 版每一级色阶交界都描 6px 粗边，平涂只在强边界勾细边，因此色块成片、轮廓线稀疏。算法版本 `local-v4`，改动算法必须同步升级版本号以失效旧缓存。

**AC「色号明显收敛」的验收口径**：收敛由每通道 4 级量化保证（风格图层面最多 64 种组合），但成品图纸的色号数还受所选色卡档与三候选策略约束，固定样图上的色号计数不稳定，因此没有把「色号数量」写成自动化断言（此前尝试过 `colors.length` 收敛断言，方向与幅度都不可靠）。成品观感与色号密度由四类素材的人工视觉回归判定。

**自动化测试覆盖**（服务端生成接口 seam）：端到端三候选、尺寸档与拼板数、色卡档归属；主体面积占比相对原图不劣化（≥0.9）、包围盒跨度 > 0.9、少色号候选色块连通（`components === 1`）；与 Q 版结果图不同，且成品格网里深色轮廓格占比明显低于 Q 版。测试只读成品格网与色号，不读风格图 PNG 像素，符合规格「不做像素级外观断言」。

**遗留人工项**：照片、插画、截图、线稿四类素材的视觉回归尚未执行，需人工过一遍并记录 `local-v4` 的结论；真机冒烟归工单 12。
