# 05 — 像素风

**What to build:** 用户选择像素风后，拿到的是像素块化且色号收敛的图纸，缩小到目标格网后仍然轮廓可辨识。

**Blocked by:** 02

**Status:** ready-for-human

- [x] 像素风端到端可用，三候选与既有不变量（色卡档、尺寸档、拼板数）成立
- [x] 像素块量化在执行分辨率上可见且稳定，缩到目标格网后不失真
- [x] 色号收敛在所选色卡档内，主体轮廓仍可辨识
- [ ] 四类素材的视觉回归通过并记录算法版本
- [x] 与其他免费风格结果互不复用，换风格必重算

## Comments

**算法**：工作图插值缩到 29×29（块内像素被平均掉，避免单点取样跳色），按每通道 4 级量化，再用最近邻放大回工作尺寸 348。块数取 29 是因为工作尺寸与成品格网对齐：348 / 29 = 12，成品大档 87 格网里每块正好 3×3 格，小档与中档降采样后也不会把像素块抹平；此前试过 44 块（348 除不尽，约 7.9px/块）且大于 29，降采样会把块状抹掉，已改掉。算法版本 `local-v4`，改动算法必须同步升级版本号以失效旧缓存。

**自动化测试覆盖**（服务端生成接口 seam）：端到端三候选、尺寸档与拼板数、色卡档归属；主体面积占比相对原图不劣化（≥0.9）、包围盒跨度 > 0.9、少色号候选色块连通（`components === 1`，高细节候选的抖动会在边界留零星噪点，因此不用它做连通性判据）；大档 87 格网按 3×3 对齐分块，颜色完全一致的块占比 > 0.8，证明像素块在成品格网里可见且稳定；小档与大档的主体占比差 < 0.1，证明缩档不失真；像素风与平涂、原图的成品格网互不相同，换风格必重算。

**遗留人工项**：照片、插画、截图、线稿四类素材的视觉回归尚未执行，需人工过一遍并记录 `local-v4` 的结论；真机冒烟归工单 12。
