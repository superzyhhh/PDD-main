# 06 — 高级风格经云函数出口

**What to build:** 被授权的用户选择动漫风或写实风时，原图经云函数出口调用生成式模型完成转换，仍得到三张可拼图纸；失败时可重试或跳过，不会被偷偷换成别的风格。

**Blocked by:** 02

**Status:** ready-for-human

- [x] 动漫风与写实风经云函数出口完成转换，云函数是唯一出口，小程序端不具备调用能力
- [x] 服务端把返回结果下载为二进制并校验可解码与尺寸上限，外链不进入缓存
- [x] 结果同样经过内容安全校验，拦截时以独立原因结束且不计入风格转换失败
- [x] 超时与限流可重试、可跳过风格按原图生成，不自动回退到其他风格
- [x] 同一原图同风格只调用一次，并发请求合并；模型版本参与缓存键
- [x] 未配置云开发时高级风格不可用，免费风格与原图不受影响
- [x] 受控替身覆盖成功、超时、拒绝、坏图四种情况，失败路径有自动化测试

## Comments

**出口契约**：服务端把工作尺寸的 PNG 连同 `x-style`、`x-model-version` 头 POST 到云函数 HTTP 触发器，可选带 `authorization: Bearer <服务令牌>`；云函数必须回图片二进制（不接受 JSON/文本外链）。响应逐项校验：非 2xx 直接失败、JSON/文本视为外链拒绝、8MB 字节上限（边读边计数，超限即取消流）、sharp 解码校验、2048×2048 像素上限。

**缓存与版本**：provider 版本为 `cloud-{模型版本}`，参与既有风格缓存键，所以同图同风格只调用一次、换尺寸档/色卡档复用、并发合并；模型升级必须改 `STYLE_MODEL_VERSION` 才能失效旧缓存。失败不写缓存，重试会重新调用。

**降级与回落**：未配置出口或配了出口却缺模型版本时，服务端只告警并关闭高级风格入口，免费风格与原图不受影响；风格转换失败记为 `style-failed`，任务仍记录用户选的风格，不会自动换成别的风格；客户端失败提示里可重试或「跳过风格，按原图生成」（复用已选图片，不重新上传）。内容安全拦截云函数输出记为独立原因 `style-blocked`，不计入风格转换失败次数。

**小程序边界**：CI 的边界扫描新增 `cloud.callFunction` / `tcb.callFunction` 特征，小程序目录内出现即失败，保证高级风格只能经服务端出口。

**自动化测试**：用本地 HTTP 桩模拟云函数，经既有生成接口 seam 覆盖成功（三候选、29 格、AI 标识、改尺寸档复用）、429 限流、超时、外链 JSON、超字节、超像素、坏图、内容安全拦截；免费风格/原图在未配置出口时的行为沿用既有用例。

**测试基建顺带修复**：Windows 动态端口起点为 1024，`listen(0)` 会偶发拿到 fetch 规范禁用的端口（如 6000、6666），导致 `fetch failed: bad port`。测试启动服务改为跳过这些端口，消除偶发红灯。

**遗留人工项**：云函数本体部署在云开发环境，真实图生图联调与动漫/写实四类素材视觉回归见部署清单「3.6 高级风格云函数」；真机冒烟归工单 12。
