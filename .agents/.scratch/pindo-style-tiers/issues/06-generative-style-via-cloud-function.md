# 06 — 高级风格经云函数出口

**What to build:** 被授权的用户选择动漫风或写实风时，原图经云函数出口调用生成式模型完成转换，仍得到三张可拼图纸；失败时可重试或跳过，不会被偷偷换成别的风格。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 动漫风与写实风经云函数出口完成转换，云函数是唯一出口，小程序端不具备调用能力
- [ ] 服务端把返回结果下载为二进制并校验可解码与尺寸上限，外链不进入缓存
- [ ] 结果同样经过内容安全校验，拦截时以独立原因结束且不计入风格转换失败
- [ ] 超时与限流可重试、可跳过风格按原图生成，不自动回退到其他风格
- [ ] 同一原图同风格只调用一次，并发请求合并；模型版本参与缓存键
- [ ] 未配置云开发时高级风格不可用，免费风格与原图不受影响
- [ ] 受控替身覆盖成功、超时、拒绝、坏图四种情况，失败路径有自动化测试
