# 02 — 流水线重排与 Q 版

**What to build:** 风格转换统一放到抠主体之后、并在目标格网的整数倍分辨率上执行；Q 版作为第一个免费风格端到端可用，用户选择 Q 版后拿到的仍是三张可直接拼的图纸。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 生成顺序统一为「解码摆正 → 抠主体 → 格网整数倍风格转换 → 降采样 → 色号匹配 → 三候选」，原图结果与改动前一致
- [ ] Q 版端到端可用，仍恰好三候选，所有色号落在所选色卡档，成品尺寸档与拼板数不变
- [ ] Q 版为比例不变、圆润简化：主体包围盒与面积占比不劣化，色块连通性不碎
- [ ] 同一原图同风格只执行一次转换；仅改尺寸档、色卡档或高级设置不重复转换；换风格必重算
- [ ] 转换失败不写入缓存，任务以可识别原因结束，用户可重试或跳过风格
- [ ] 缓存键使用算法版本，算法版本变化后旧缓存失效
- [ ] 固定样图覆盖照片、插画、截图、线稿四类，Q 版通过人工视觉回归并记录算法版本
