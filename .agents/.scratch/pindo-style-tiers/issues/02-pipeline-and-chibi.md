# 02 — 流水线重排与 Q 版

**What to build:** 风格转换统一放到抠主体之后、并在目标格网的整数倍分辨率上执行；Q 版作为第一个免费风格端到端可用，用户选择 Q 版后拿到的仍是三张可直接拼的图纸。

**Blocked by:** 01

**Status:** ready-for-human

- [x] 生成顺序统一为「解码摆正 → 抠主体 → 格网整数倍风格转换 → 降采样 → 色号匹配 → 三候选」，原图结果与改动前一致
- [x] Q 版端到端可用，仍恰好三候选，所有色号落在所选色卡档，成品尺寸档与拼板数不变
- [x] Q 版为比例不变、圆润简化：主体包围盒与面积占比不劣化，色块连通性不碎
- [x] 同一原图同风格只执行一次转换；仅改尺寸档、色卡档或背景模式以外的高级设置不重复转换；改背景模式或换风格必重算
- [x] 转换失败不写入缓存，任务以可识别原因结束，用户可重试或跳过风格
- [x] 缓存键使用算法版本，算法版本变化后旧缓存失效
- [ ] 固定样图覆盖照片、插画、截图、线稿四类，Q 版通过人工视觉回归并记录算法版本

## Comments

- 流水线改为「解码摆正 → 抠主体 → 风格转换 → 降采样 → 色号匹配 → 三候选」：主体只裁一次，风格转换与出图共用同一份主体图；原图风格也走同一份主体图，结果与改动前一致。
- 风格转换在固定工作尺寸（348，最大成品格网 87 的 4 倍）上执行，与成品尺寸档解耦，因此仅换尺寸档不会重新转换；工作图按比例铺满方形画布，与出图降采样的口径一致，主体面积占比不因留白而下降。
- 缓存键为「原图内容 + 风格 + 算法/模型版本 + 背景模式」。背景模式会改变风格输入（整图或抠出的主体），必须计入键；规格与工单已同步修正「仅改高级设置不重复转换」的表述。
- Q 版算法（版本 `local-v2`）：3×3 均值平滑 → 每通道 5 级量化 → 色块边界 6px 深灰轮廓，比例不变，只做圆润简化。
- 自动化覆盖结构性不变量（三候选、尺寸档、拼板数、色卡档、主体占比不劣化、非白格网连通块为 1），不做像素级外观断言；观感以人工视觉回归为准。
- 未覆盖：固定样图的四类人工视觉回归（照片、插画、截图、线稿）仍需人工执行并记录 `local-v2` 结论；真机冒烟归工单 12。
