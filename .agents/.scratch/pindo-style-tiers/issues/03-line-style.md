# 03 — 线条风

**What to build:** 用户选择线条风后，照片会被转成以轮廓为主的风格并生成三张可拼图纸；上传的本来就是线稿时，不会被重复描边。

**Blocked by:** 02

**Status:** ready-for-human

- [x] 线条风端到端可用，三候选、色卡档、成品尺寸档与拼板数断言全部成立
- [x] 输入为线稿时做幂等处理，不重复描边、不出现双线
- [x] 输入为照片时能提取可辨识轮廓，色块连通性不碎
- [ ] 四类素材（照片、插画、截图、线稿）的视觉回归通过并记录算法版本
- [x] 与其他免费风格结果互不复用，换风格必重算

## Comments

- 线条风算法（版本 `local-v3`）：平滑后取 Sobel 梯度，常规阈值 110，边缘过少（低于 0.2%）自动退回 45 重算，避免低对比度素材输出全白；边缘向外扩 4px 成为描边，缩到成品小档格网仍可辨识。输出白底深灰线条，不做阈值剪影。
- 线稿幂等判定不再依赖彩度（彩色线稿会被漏判而二次描边）：白底占比 ≥ 40%，且非白像素中「周围 25px 邻域整块非白」的实心区域不超过 10%，即视为线稿，直接灰度化保留原笔迹。实测黑白线稿、蓝色线稿都走幂等分支，红底圆形插画仍走边缘提取。
- 线稿判定与 Sobel、描边之间共享新增的 `boxBlur3`，Q 版同时改用它，去掉重复的平滑实现；轮廓墨色合并为一个常量。
- 自动化覆盖结构性不变量（三候选、尺寸档、拼板数、色卡档、轮廓包围盒、线条面积占比、连通块数、线稿描边面积不翻倍），不做像素级外观断言。
- 未覆盖：照片、插画、截图、线稿四类固定样图的人工视觉回归仍需人工执行并记录 `local-v3` 结论；真机冒烟归工单 12。
