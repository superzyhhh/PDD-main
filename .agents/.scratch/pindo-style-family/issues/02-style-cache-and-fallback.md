# 02 — 风格缓存与失败降级

**What to build:** 同一张原图、同一种风格只调用一次风格服务；只改成品尺寸档、色卡档或高级设置时复用已风格化图片，不重复调用；换风格必重新风格化并重新出图。风格服务超时、报错或返回坏图时，任务以「风格化失败」结束，玩家可以一键跳过风格、按原图继续生成，不需要重新上传或重选图片。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 同图同风格重复提交复用结果，不重复调用风格服务
- [ ] 仅改成品尺寸档、色卡档或高级设置时，复用已风格化的图片，不重复调用风格服务
- [ ] 换风格必产生新图纸，不命中旧风格的结果
- [ ] 风格服务超时、非成功响应或返回不可解码图片时，任务以「风格化失败」结束且不产出候选
- [ ] 风格化失败后，玩家可一键跳过风格、按原图继续生成，无需重新上传或重选图片
- [ ] 假风格服务可稳定模拟成功、超时、错误响应、坏图四种情况
- [ ] 自动化测试通过调用记录断言缓存命中与换风格重算，并覆盖四种失败情况的用户可见结果
