# 03 — 风格维度看板与失败样本

**What to build:** 运营者可以在既有时间与渠道过滤下，按风格看到生成任务数、生成用户数、首图接受数与接受率，以及风格化失败次数与失败率；失败样本记录、列表与 CSV 导出都带风格字段，便于按风格定向分析。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 看板汇总在时间与渠道过滤下，按风格给出生成任务数、生成用户数与首图接受数、接受率
- [ ] 看板按风格给出风格化失败次数与失败率，同一任务只计一次
- [ ] 失败样本记录、后台列表与 CSV 导出包含风格字段，既有列与时间过滤保持不变
- [ ] 风格维度不改变原有生成到付费漏斗、7 日二次生成与盲测统计口径
- [ ] 自动化测试覆盖按风格拆分、失败计数去重、CSV 含风格列，以及时间与渠道过滤叠加
