# 01 — 一条通天：上传即出图纸

**What to build:** 用户在小程序里选一张图并上传，云端完成智能抠图、自动减色与 MARD 221 色号映射，返回一张 29×29 的低精度图纸，小程序用原生 canvas 渲染出来，用户能确认主体是否抠对。这一条同时打通静默登录、上传即过内容安全、超时与重试提示，以及 CI 中的 GPL 边界检查（小程序产物不含引擎代码）。

**Blocked by:** None — can start immediately

**Status:** ready-for-human

- [x] 选图上传后，在约定时限内看到 29×29 的图纸预览，格网、色块与色号标注可辨认（代码完成；canvas 观感待真机冒烟）
- [x] 所有色号都属于 MARD 221，不出现档外色号
- [x] 原图存在明确主体时主体可辨识；不可用图片返回可理解的原因，不暴露技术错误码
- [x] 上传内容命中内容安全时任务被阻断，用户看到「换张图」提示，阻断事件留痕
- [x] 网络超时或任务失败时可一键重试，不产生重复扣费（计费尚未引入，按内容哈希复用任务）
- [x] CI 检查通过：小程序产物不包含任何来自云端的引擎源码或编译产物
- [x] 云端生成接口的 seam 测试覆盖：候选结构完整、格尺寸与色卡档一致、色号全在色卡内

## Comments

实现于 `d:/PDD/pindo-miniapp/`（独立 git 仓库）：

- 服务端：`server/src`，Node + sharp 解码，vendor 的 Pindo 引擎只跑在容器内（ADR-0001），小程序端从零实现。
- 接口：`POST /api/session`、`POST /api/generate`（octet-stream）、`GET /api/tasks/:id`；上传即过内容安全，命中返回 422 并写 audit 日志。
- 色卡：基础档 221 由数据推导为 A–H（206）+ M（15），模块加载时校验总数必须为 221；数据来源仍受 ADR-0002 约束。
- 验证：`npm run ci`（typecheck → 构建 + GPL 边界检查 → 7 个测试全绿）。
- 待人工冒烟：微信开发者工具中选图 → 预览（`BASE_URL` 已指向本机局域网 `http://10.15.0.79:3000`；真机还需真实 AppID 与同一网络）。
- 未覆盖：真实计费（工单 04/05）、中/大尺寸与 291 档（工单 03）、真机 canvas 观感。
