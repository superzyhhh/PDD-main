# 08 — 高级设置与逃生动作

**What to build:** 主流程保持零参数；抖动、背景处理、色号上限、降采样模式、系列色过滤收进默认折叠的「高级设置」，改动后重新生成生效。三候选全不满意时出现且仅出现「换张图」「裁主体」两个动作，失败样本（原图、参数、三候选）入库。

**Blocked by:** 02

**Status:** ready-for-human

- [x] 默认界面看不到任何高级参数，展开后可调并影响生成结果
- [x] 高级参数改动有明确生效反馈，不需要用户猜
- [x] 三候选全不满意时展示且仅展示「换张图」「裁主体」两个动作
- [x] 三个都不满意被记录为失败样本，可按时间在后台查询

## Comments

- 主流程仍只有成品尺寸档与色卡档位。「高级设置」默认收起，展开后可调抖动、背景处理、色号上限、降采样模式与系列色；每个参数保留「自动」或「全部」选项，恢复后即回到三候选各自的策略。引擎的「有序抖动」是原样返回的占位实现，不向用户暴露。
- 高级参数随生成请求提交并参与内容寻址：同一张图同一组参数复用已有图纸，换任意参数必然重新生成，不会误用旧图纸。
- 生效反馈分两层：改动后面板提示「重新生成后生效」并给出「按当前设置重新生成」入口；生成完成后回显「本次已应用 · 抖动/背景/色号/降采样/系列」摘要，用户不需要猜参数是否生效。参数全为自动时不显示摘要，保持零参数主流程干净。色号上限是整体封顶，各候选仍按自己的策略收紧，面板文案已说明。
- 背景处理按引擎能力收敛为「自动裁背景」与「保留整图」：引擎的白底与黑底裁切行为等价，无法再细分底色，因此不向用户暴露无效选项。
- 系列色过滤按 MARD 系列（A–H、M、P/Q/R/T/Y/ZG）多选；基础档只给基础与灰阶系列，切到基础档会自动清掉进阶系列并提示，避免生成时才发现过滤后无可用色号。
- 三候选全不满意是明确的逃生状态：预览页底部才有入口，进入后只出现「换张图」「裁主体」两个动作，不提供重试或继续调参。进入时把原图、成品尺寸档、色卡档位、高级参数与三候选一起留档；同一任务只留档一份，客户端与服务端都按任务号去重。上报失败会在页面上如实显示，不假装已记录。
- 「裁主体」打开微信自带裁剪界面圈出主体，裁完按当前参数重新生成；当前微信版本不支持裁剪时明确提示换一张图，不静默失败。
- 失败样本在内存中保留最近 50 条，后台按失败时间倒序查询，可看原图、参数与三候选。查询需要后台口令，未配置口令时接口不开放；未登录任务凭任务号上报，登录任务仅本人可上报。
- 验证：类型检查、GPL 边界检查与 47 个测试全绿。新增 9 条接口 seam 测试覆盖四条验收，并额外覆盖参数非法回退、系列过滤越界、重复进入不满意去重、越权上报与后台口令缺失。
