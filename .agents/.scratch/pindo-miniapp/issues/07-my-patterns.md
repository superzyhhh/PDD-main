# 07 — 我的图纸

**What to build:** 登录用户生成的图纸自动保存在「我的图纸」，最多保留最近 50 张；超出时淘汰最旧并提示；可删除、可重新打开并再次导出。

**Blocked by:** 04

**Status:** ready-for-human

- [x] 生成后图纸自动入列表，按时间倒序展示
- [x] 第 51 张触发最旧一张被淘汰，并给出明确提示
- [x] 删除即时生效，列表与存储一致
- [x] 旧图纸可重新打开并导出，导出图纸与首次一致（缓存命中）
- [x] 未登录用户生成的图纸不落库，登录后从新生成开始保存

## Comments

- 服务端按账号保存图纸，最多 50 张。登录用户生成完成时自动保存默认候选（保主体细节）；换候选时原地更新同一张图纸，不新增条目。列表展示尺寸、色号数、拼板数、候选类型与保存时间，打开某一张时再取完整图纸。
- 未登录生成的图纸不保存；只有生成者本人才能保存。已删除或不属于当前账号的图纸按不存在处理，不向他人泄露。同一张图在不同账号之间不复用任务，保证每个登录账号生成后都能进入自己的「我的图纸」。
- 超出 50 张时清理最早保存的一张。客户端在生成完成且发生清理时弹窗告知「只保留最近 50 张、最早的 n 张已清理」，已保存到相册的图片不受影响。
- 重新打开旧图纸可直接导出，导出图纸与首次一致、命中缓存且不重复扣减额度。删除后再次导出按不存在处理。
- 客户端新增「我的图纸」列表页，支持打开与删除；首页加入口。打开某张后回到首页直接进入可导出的预览；「换一张图」清除重开状态。删除即时刷新列表。
- 验证：类型检查、GPL 边界检查与 38 个测试全绿。新增 7 条接口 seam 测试覆盖五条验收，并额外覆盖他人图纸不可读、不可删、不可导出。
