# 05 — 会员开通与权益

**What to build:** Android 端可用微信支付开通月卡 9.9 元、年卡 69 元；开通后立即解锁无限高清导出与 291 档位；到期后权益收回，但已保存的图纸仍可查看与导出。iOS 端只展示权益，不出现任何购买按钮、价格或虚拟商品文案（ADR-0003）。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] Android 端支付完成后会员状态即时生效，无限导出与 291 可用
- [ ] iOS 端不出现可触发的购买按钮、价格或虚拟商品文案
- [ ] 会员到期后权益收回，已保存图纸仍可查看并按免费额度导出
- [ ] 权益以服务端为准，换设备后状态一致
- [ ] 支付失败或取消不改变会员状态，不产生脏数据
