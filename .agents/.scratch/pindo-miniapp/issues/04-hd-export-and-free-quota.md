# 04 — 高清导出与免费额度

**What to build:** 用户可导出高清无水印整图；免费用户每日 1 次，额度由服务端校验与计数，客户端状态不可信；同一图纸同类型导出复用缓存、不重复扣次；未登录用户导出前引导登录，登录后额度正确继承。

**Blocked by:** 03

**Status:** ready-for-human

- [x] 导出得到高清无水印图纸，网格线与色号标注清晰可打印
- [x] 免费账号当日第 2 次导出被服务端拒绝，给出明确额度提示与会员入口
- [x] 服务端为额度唯一权威，篡改本地状态不会增加次数
- [x] 同一图纸重复导出不扣次，且命中缓存
- [x] 未登录用户导出被引导登录，登录后额度正确继承

## Comments

- 服务端新增 `POST /api/exports`：先由会话令牌解析 openId，未登录返回 401；再校验任务已完成、候选存在、任务归属。额度按上海自然日与 openId 计 1 次，先扣后出图，渲染失败自动归还。
- 缓存键包含 openId、任务与候选，同一账号同一图纸同类型命中缓存不扣次；不同账号导出同一张匿名图纸各自计费，不能复用他人资源。
- 同一账号同一键的并发出图只渲染一次，避免双击重复扣次。
- 高清 PNG 每格 40px，逐格填色并标注色号，画格线与每 29 格拼板分界线；输出为不透明 PNG，无水印。
- 下载接口要求登录，且只能下载本账号创建的导出资源。
- 客户端预览页新增「导出高清图纸」：401 时静默重新登录并重试一次；429 弹额度提示，非 iOS 提供会员权益入口；相册权限不足时引导去设置。
- 新增会员权益页，仅展示权益列表，无价格与购买入口（遵循 ADR-0003）；实际开通与无限额度随工单 05。
- 验证：类型检查、GPL 边界检查与 19 个测试全绿，其中导出接口 7 条覆盖未登录、首导、缓存复用、额度拒绝、账号额度继承、跨账号隔离与归属校验。真机相册保存与打印观感归工单 12。
