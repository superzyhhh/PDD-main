# 02 — 三候选与首图接受

**What to build:** 同一次生成产出三张候选（保主体细节 / 保色彩层次 / 保少色号），顺序固定，用户选一张即进入图纸详情。用户选中第一张即记录「首图接受」。同一张原图与同一参数组合重复提交命中内容寻址缓存，返回相同候选且不新增扣费。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 一次生成返回恰好 3 个候选，顺序固定，第一张为「保主体细节」
- [ ] 三候选至少在色号数或降采样策略上互不相同，用户能看出差异
- [ ] 选中任一张后进入图纸详情，选中第一张触发首图接受事件
- [ ] 同图同参数再次提交命中缓存，返回相同候选，耗时明显下降且不重复计费
- [ ] 埋点事件名与字段契约确定，可被后续看板消费
