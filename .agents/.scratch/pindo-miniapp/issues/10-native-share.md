# 10 — 原生转发

**What to build:** 图纸可生成小程序卡片转发给好友或群，接收者打开即可查看该图纸；查看页不暴露生成者的其他图纸。

**Blocked by:** 07

**Status:** ready-for-human

- [x] 图纸可转发为小程序卡片，标题与封面正确
- [x] 接收者打开后可查看图纸，无需登录
- [x] 越权访问他人图纸被拒绝，仅能看被分享的那一张
- [x] 分享次数与来源可统计

## Comments

- 只有选中候选后才能发起分享：未选中时右上角转发入口收起，「分享给好友」按钮也不出现；选中候选后两种入口走同一套原生分享，卡片标题统一为「尺寸 · 色号数」，封面由服务端按图纸格网渲染成 640×640 PNG。
- 发起分享时把当前候选深拷贝成一条分享记录，并生成不可猜的分享号；分享页只按分享号取这一张，不带任务号、账号或其他图纸信息，因此接收者无法访问生成者的「我的图纸」。
- 接收者无需登录即可查看；分享页展示封面、尺寸、拼板数与色卡档位，长按可保存或再次转发。接收者再转发沿用同一分享号，不新建记录，标题与封面与首次分享一致。
- 分享失败（含登录失效）不伪装成图纸卡片，而是退回首页通用卡片，避免指向一个打不开的分享页。
- 匿名生成的图纸也能分享，但只有任务本人能对登录任务发起分享；不存在或未完成的图纸、错误候选都会被拒绝。
- 统计以分享记录为单位：记录来源（右上角菜单 / 页面按钮）、打开次数与创建时间；打开次数按请求累加、不去重，接收者再转发不产生新的分享记录。后台凭后台口令查询总次数与明细。分享记录最多保留 500 条。
- 验证：类型检查、GPL 边界检查与 53 个测试全绿。新增 4 条分享接口 seam 测试，覆盖免登录查看、越权拒绝、匿名分享与后台统计。
