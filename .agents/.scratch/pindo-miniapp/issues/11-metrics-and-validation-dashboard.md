# 11 — 埋点与验证看板

**What to build:** 产出验证期四闸门所需数据：首图接受率、生成 → 付费转化、7 日内二次生成、盲测胜率记录；并提供失败样本查询与导出，支撑 2—4 周验证。

**Blocked by:** 02, 05, 07

**Status:** ready-for-human

- [x] 首图接受率可按时间与渠道统计
- [x] 生成 → 付费漏斗可查，含免费额度耗尽到会员开通的转化
- [x] 7 日内二次生成可按同一用户计算
- [x] 盲测记录（20 人 × 5 组）可录入并自动计算 pairwise 胜率
- [x] 失败样本可按时间导出

## Comments

- 渠道归因：小程序冷启动读取链接上的 `channel` 参数并存入全局，生成时随请求上报；服务端只接受短小写标识，缺失或非法值统一记为「直接访问」，因此看板不会因脏参数出现碎渠道。
- 首图接受率：分母是查询区间内完成生成的图纸数（匿名图纸也计入），分子是同一批图纸中触发「首图接受」的数量；同一张图纸重复上报只记一次，避免接受率被刷过 100%。支持按时间区间与渠道筛选，区间端点含在统计内。
- 生成 → 付费漏斗：依次统计生成用户、免费额度耗尽用户、会员开通用户，三步都限定在同一批生成用户内；「额度耗尽到开通」只认耗尽之后发生的开通，反映付费点是否真的促成转化。
- 7 日内二次生成：以用户首次生成时间为锚点，只有首次生成落在查询区间内的用户才进入分母；7 日内再次完成一张新图纸计入复购。匿名生成不计入用户；同图同参数命中缓存不产生新图纸，也不算二次生成。
- 盲测：按「测试者 + 组 + 对比项」覆盖录入，重复提交不重复计数；后台输出总记录、去重后人数与组数，以及每个对比项的胜/负/平票与相互胜率，平票不计入胜率分母。20 人 × 5 组录入后可直接核对人数 20 与 5 个对比项。
- 失败样本导出：CSV 含样本号、图纸号、账号、成品尺寸档、色卡档、生成设置、创建时间与原图地址，按创建时间区间导出；含逗号、引号或换行的字段按 CSV 规则转义。
- 权限与保留：看板与失败样本导出都要求后台口令，未配置时接口视为未启用；数据保留在服务端进程内（看板事件与盲测记录各 2000 条、失败样本 50 条），重启会清零，验证期结束前需接入持久化存储。
- 验证：类型检查、GPL 边界检查与 59 个测试全绿。新增 6 条看板 seam 测试，覆盖渠道与时间筛选、额度耗尽到开通漏斗、7 日复购、盲测覆盖与胜率、失败样本 CSV 导出、后台口令开关。
