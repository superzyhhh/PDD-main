# 09 — 材料清单与去购买

**What to build:** 图纸详情展示色号、每种数量与预估包数，并提供「去购买」跳转。本版不接佣金、不做下单、不采集收货信息。

**Blocked by:** 03

**Status:** ready-for-human

- [x] 材料清单与图纸实际用量完全一致（逐色号核对）
- [x] 显示预估包数，换算规则与实际数量一致
- [x] 「去购买」跳转到外部购买路径，不产生订单与佣金
- [x] 291 图纸清单明确区分 221 内与需额外采购的色号

## Comments

- 材料包清单由服务端随图纸一起下发，逐色号保留色号、名称、用量与预估包数，顺序与用量统计一致；测试逐行核对清单与色号矩阵重算结果。
- 换算规则按 MARD 材料包每包 1000 颗、向上取整；清单只用于备料参考，不改变图纸本身的用量与导出结果。
- 291 档下，属于基础 221 系列（A–H、M）之外的色号标「额外」，并在清单顶部提示额外采购数量；基础档不会出现「额外」标记。
- 「去购买」不创建订单、不采集收货信息、不接佣金：配置材料包购买地址时进入外部购买页；未配置地址时复制清单并提示到购物 App 按色号搜索。外部购买页需在小程序后台配置业务域名。
- 材料清单超过 10 行时在清单内滚动，避免长清单把导出按钮挤出屏幕。
- 验证：类型检查、GPL 边界检查与 49 个测试全绿。新增材料包换算单元测试，并在生成接口 seam 测试中逐色号核对清单与用量。
