# 06 — 分块打印导出

**What to build:** 大图纸可导出为按 A4 分页的分块打印图，每页带对齐坐标、页码与拼板编号，分页覆盖完整且不重不漏；图纸详情展示拼板数量。

**Blocked by:** 04

**Status:** ready-for-human

- [x] 大档 87×87 图纸可按 A4 分页导出，页数正确
- [x] 分页覆盖全图，无遗漏、无重复（分块纯函数 seam 断言）
- [x] 每页含对齐坐标与页码，拼板编号与实物底板对应
- [x] 每页格数不超过 A4 在目标 DPI 下的可读上限
- [x] 图纸详情展示拼板数量，与导出页数一致

## Comments

- 新增分块导出纯函数：按 29 格一块拼板切页，行优先排列（先从左到右，再从上到下），页数恒等于拼板数。小/中/大成品尺寸分别为 1/4/9 页；每页恰好一块板，因此分页天然覆盖全图、不重不漏。
- 每页 A4 300 DPI（2480×3508px）栅格化，单格 64px 约 5.4mm；页眉给出「第 x / y 页 · 拼板 n」与全图列/行区间，上边与左边逐格标注该格在整张图纸中的绝对列号/行号，四角有对齐标记，便于跨页对齐与实际裁切。
- 导出接口在既有 `POST /api/exports` 上增加 `type`：默认 `hd`（高清整图 PNG），`tiled`（A4 分块打印 PDF）；缓存键按 openId + 任务 + 候选 + 类型区分，同一类型命中缓存不重复渲染、不扣次；下载地址按资源类型返回 `.png` / `.pdf`，并按记录格式校验，避免用错误后缀取资源。
- PDF 由项目内的最小 PDF 写入器生成，每页嵌入一张 JPEG 图像，无新增依赖；容器化部署时需保证中文字体可用（页眉使用 微软雅黑/PingFang/Noto CJK 回退栈）。
- 免费额度按次共用于高清与分块导出：免费账号当天导出一次后，另一类型同样返回 429；会员仍然无限。这也避免用分块 PDF 绕过每日导出额度。
- 客户端详情页展示拼板数，并新增「导出 A4 分块打印图（n 页）」按钮；导出后下载 PDF 并用 `wx.openDocument` 打开，用户可从右上角菜单保存或打印。
- 验证：类型检查、GPL 边界检查与 31 个测试全绿。其中分页纯函数覆盖 29/58/87 三档的页数、行列区间、覆盖不重不漏与单格物理尺寸；接口测试覆盖 PDF 下载与页数、缓存不扣次、额度共用、大档 9 页。

## 待人工确认

- 分块 PDF 的实际打印观感：格线、色号字号与 5.4mm 单格在真实打印机上的清晰度，归工单 12 真机冒烟。
- 生产容器需自带中文字体，否则页眉中文会回退成方框；部署时需在镜像内安装 CJK 字体。
