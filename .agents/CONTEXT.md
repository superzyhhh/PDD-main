# 拼豆图纸生成小程序

面向 C 端拼豆新手的一键出图工具：上传图片，不做参数调整即得到可直接照着拼的 MARD 色号图纸。B 端门店工具不在本期范围。

## Language

**图纸**:
一张由格网与色号构成、可直接照着拼的作品说明，是产品的唯一交付物。
_Avoid_: 效果图、预览图、图纸图片

**色号**:
色卡内的唯一编码（如 A01），玩家按它取豆。
_Avoid_: 颜色、色值

**色卡档位**:
MARD 的两个可选色号集合——基础档 221（对应玩家手上的常见套装）与进阶档 291（会员可用）。
_Avoid_: 色板、配色方案

**风格族**:
生成前可选的视觉风格集合，由「原图」与五种通用视觉风格（动漫风、Q 版、像素风、写实风、线条风）组成；「原图」表示不做风格化。不包含任何命名 IP。
_Avoid_: IP 风格、角色风格、XX 同款

**零失败**:
用户上传原图后不做任何参数调整，首次生成结果即被接受且无需重试的产品承诺。
_Avoid_: 一键生成、傻瓜式

**首图接受率**:
盲测中用户表示「愿意直接用」的首图占比，是针对「零失败」的主验收指标。
_Avoid_: 成功率、满意度

**成品尺寸档**:
成品尺寸的三档口径——小 29×29（1 块板）、中 58×58（4 块板）、大 87×87（9 块板），是主流程中唯一直接暴露给用户的尺寸选择。
_Avoid_: 分辨率、图片尺寸

**候选**:
同一次生成产出的三张图纸（保主体细节 / 保色彩层次 / 保少色号），用户从中选一张即完成出图。
_Avoid_: 结果、版本、方案

**材料包**:
按一张图纸的实际色号用量打包出售的实体拼豆与底板。
_Avoid_: 材料、耗材
